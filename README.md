# Emailr

Emailr is a gamified web app that teaches high schoolers practical email etiquette through short lessons, branching scenarios, inbox challenges, points, and badges.

## What students practice

- Writing clear subject lines
- Choosing an appropriate tone
- Including context and a specific ask
- Following up respectfully
- Proofreading before sending

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```
